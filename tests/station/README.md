# 🧪 Тесты станции

[← Главная](../../README.md) · [Как внести изменение](../../CONTRIBUTING.md)

Основной набор: [test_station.py](test_station.py). Запуск из исходников или готового пакета:

```bash
./station.sh test
```

| Область | Что проверяется |
|---|---|
| Файловый вход | Стабильность, маркеры, изменение данных, неполные/ошибочные входы |
| Очередь | Повторные попытки, восстановление после сбоя, отсутствие повторной публикации при прежних условиях |
| Изображения | Превью, сохранность оригинала, обработка JSON |
| HTTP | Только чтение, допустимые пути, состояние воркера |
| Упаковка | Контрольные суммы и отдельные контрактные ограничения |

> [!IMPORTANT]
> В тестах используются синтетические данные; в части проверок native-вызов подменяется. Это не испытание реального RF-декодирования, драйверов, графики и мандатных политик Astra. Не называйте 23 прошедших теста готовым бинарным релизом.

Python должен иметь Pillow; готовый пакет использует собственный runtime. В CI отдельно проверяется Python 3.5/Pillow из Stretch. Документационные тесты находятся в `tests/docs` и решают другую задачу.
