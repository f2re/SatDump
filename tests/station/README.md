# Проверки Station

[Главная](../../README.md) · [Порядок изменений](../../CONTRIBUTING.md)

Из корня исходников либо полного пакета:

```bash
./station.sh test
```

| Набор | Контракт |
|---|---|
| [test_station.py](test_station.py) | Входы, очередь, изображения, HTTP и упаковка |
| [test_board_infra.py](test_board_infra.py) | BOARD, авторизация, ревизии, мастер установки и службы |
| [test_timebase.py](test_timebase.py) | UTC, переход через полночь, скачки часов, повторы |
| [test_product_quality.py](test_product_quality.py) | Обязательные приборы, неполные наборы, восстановление публикаций |

Нужен Python с Pillow. В пакете используется встроенная среда. Проверки, которым требуется отсутствующий nginx, root или Git, отмечаются как пропущенные. Количество тестов берётся из вывода запуска, а не из этого README.

Часть вызовов SatDump подменяется контрольными исполняемыми файлами. Проверка настоящего движка находится отдельно в [tests/meteor/test_native_products.py](../meteor/test_native_products.py) и `satdump-mtvza-reader-test`. Она тоже использует синтетические данные и не подтверждает калибровку, радиоприём или мандатные политики Astra.

[Тесты документации](../docs/) проверяют ссылки и согласованность контрактов. [Тесты сайта](../web/README.md) проверяют сообщения, безопасность текстового вывода и сохранение состояния страницы. Node.js нужен только машине разработчика, не установленной станции.
