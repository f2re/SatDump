# Проверки галереи

[Главная](../../README.md) · [Галерея и справка](../../docs/ru/station/WEBSITE.md)

Запуск из корня исходников с Node.js 18 или новее:

```bash
node --test tests/web/*.test.js
node --check services/station/web/app.js
node --check services/station/web/status.js
```

Сторонние JavaScript-пакеты не требуются. Проверяются независимость UTC от часового пояса, неизвестное время, различие неполного и непроверенного набора, внешние изображения, число строк и изображений, приоритет ошибок источника, локальные сценарии и разделение отчёта с паспортом.

Модульные тесты не запускают браузер. Визуальная приёмка выполняется отдельно: узкий и широкий экран, клавиатура, раскрытие справки, исходный паспорт, отсутствие источника, старый каталог без отчёта и новый частичный набор. Node.js не требуется установленной Station.
