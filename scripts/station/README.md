# 📦 Скрипты станции

[← Главная](../../README.md) · [Сборка и выпуск](../../docs/ru/station/BUILD_RELEASE.md)

Обычный пользователь начинает с корневого `station.sh` или `install.sh`. Эти файлы — реализация, а не набор взаимозаменяемых установщиков.

| Сценарий | Где выполняется | Назначение |
|---|---|---|
| [build.sh](build.sh) | Исходники, Linux x86_64 | Сборка движка glibc224, окружения, полного архива |
| [bundle-python.sh](bundle-python.sh) | **Внутри** выделенного Stretch rootfs | Комплектование отдельного Python/Pillow; не запускать на рабочей Astra |
| [pack.py](pack.py) | Подготовленная сборочная среда | Проверка компонентов, ABI, документация, манифест и архив |
| [install.sh](install.sh) | Целевая Astra, готовый пакет | Пользователи, пути, systemd, проверки запуска и переключение версии |
| [deploy.sh](deploy.sh) | Машина с SSH-маршрутом | Передача проверенного архива и запуск установщика |

> [!WARNING]
> Сборка имеет доступ к rootfs и может загружать зависимости. Офлайн-установка готового пакета — отдельный сценарий, который этого не делает. Не меняйте пути chroot на системные каталоги рабочей машины.
