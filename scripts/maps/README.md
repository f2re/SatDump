# Русские названия городов: Natural Earth → SatDump

Ветка `release/1.2.2`. Значения `NAME_RU` из указанного ниже источника
копируются дословно в `properties.name_ru` существующего GeoJSON. Это перенос
данных, а не машинный перевод и не транслитерация. Исходные `name`, `nameascii`,
идентификаторы, все прочие свойства, геометрия, состав и порядок объектов
сохраняются. Меняется только поле `name_ru` и форматирование JSON.

## Источник и воспроизводимость

Источник пользователя:
https://raw.githubusercontent.com/martynafford/natural-earth-geojson/refs/heads/master/10m/cultural/ne_10m_populated_places.json

Закреплён снимок `90266457d82d3717e47313e72a921e31a087d2c4`
репозитория `martynafford/natural-earth-geojson` — Natural Earth 4.0.0,
9 ноября 2017 года. Это не новый справочник: более поздние названия не
подставляются, поскольку требуется идентичность именно этому источнику.
SHA-256 исходного файла:
`536ed7d8b1618e999d0569f69300e642b8b6a62234fb516fedfee0bb2901609f`.

Скрипт проверяет контрольную сумму закреплённого источника. Его локальная копия
распознаётся по тем же байтам; результат и отчёт не зависят от пути к копии.
Другой файл можно явно передать через `--source`; в этом случае отчёт не
приписывает ему версию закреплённого источника, а прежние исключения не применяются.
Для новой версии данных необходимо отдельно проверить соответствия и пропуски.

| Объектов в источнике | 7 343 |
| Однозначно сопоставленных объектов SatDump | 7 340 |
| Непустых русских названий, скопированных дословно | 6 209 |
| Сопоставленных объектов с пустым переводом в источнике | 1 131 |
| Объектов SatDump, отсутствующих в источнике | 2 |
| Необъяснённых или неоднозначных соответствий | 0 |

`Leh` (`ne_id=1730025033`) и `Amaravati` (`ne_id=1730025037`)
отсутствуют в этом снимке. Они не удалены и не подменены соседними городами:
добавлено `name_ru: null`. Всего без готового русского названия остаются 1 133
объекта. Отсутствующие переводы нельзя получить из данного источника без
привлечения других данных. Проверяется точность переноса, а не актуальность
и лингвистическая правильность самого справочника.

Примеры дословного результата: `Norilsk → Норильск`, `Noyabrsk → Ноябрьск`,
`Tolyatti → Тольятти`, `Bodo → Будё`.

## Запуск

Требуется Python 3.6 или новее; сторонние пакеты не нужны. Команды из корня репозитория:

```sh
# Обновить каталог и отчёт, используя закреплённый HTTPS-источник.
python3 scripts/maps/sync_city_names_ru.py

# Проверить соответствие без записи каких-либо файлов.
python3 scripts/maps/sync_city_names_ru.py --check

# Обработка без сети: заранее сохранённая точная копия источника.
python3 scripts/maps/sync_city_names_ru.py --source /path/to/ne_10m_populated_places.json

# Сохранить отдельный результат, не заменяя исходный каталог.
python3 scripts/maps/sync_city_names_ru.py \
  --source /path/to/ne_10m_populated_places.json \
  --output /tmp/cities-ru.json --report /tmp/cities-ru.report.json
```

Параметр `--target` задаёт исходный каталог, `--output` — результат
(по умолчанию заменяется `--target`), `--report` — отчёт, `--matches` —
проверенные соответствия для закреплённого источника. Результат записывается
атомарно через временный файл в том же каталоге. При неоднозначности или
неизвестном пропуске каталог не перезаписывается; в отчёте сохраняется ошибка,
код завершения — `1`. Повторный успешный запуск даёт побайтово тот же JSON и отчёт.
`--check` проверяет смысловое равенство данных и ничего не перезаписывает.

## Как сопоставляются объекты

1. Геометрические координаты с округлением до шести знаков и проверка страны:
   6 273 соответствия.
2. Совпадение имени/допустимого исходного варианта и страны при расстоянии
   не более 100 м: 737. При наличии уникального `ne_id` в обоих файлах также
   поддерживается сопоставление по нему с проверкой страны и расстояния.
3. Исторические `longitude`/`latitude` в свойствах SatDump, исходное имя и
   страна, расстояние до геометрии источника не более 1 м: 315.
4. Проверенные пары различающихся версий: 15. Они перечислены в
   `city_names_ru.matches.json`; каждая пара закреплена хешами исходных объектов.

Поле `ne_id` в каталоге SatDump уникально, но в данном источнике оно отсутствует.
Поэтому нельзя просто соединить файлы по нему. В 15 исключениях сопоставление
дополнительно проверено по стране, имени либо `LS_NAME`, административной области
и другим исходным атрибутам. Различия геометрии зафиксированы в метрах; геометрия
источника никогда не переносится в SatDump. Файл исключений содержит идентичности
объектов, а не собственные русские переводы. Для двух отсутствующих объектов
закреплены явные исключения с `source_index: null`.

Сопоставление взаимно однозначно. Повторное использование объекта источника,
изменение проверенного объекта или конфликт с автоматическим соответствием
останавливает обработку. Нечёткое сравнение имён и выбор ближайшего города
без подтверждения идентичности не используются.

## Подписи в C++

`src-core/common/map/city_name_resolver.h` выбирает название из данных.
`src-core/common/map/city_labels.cpp` вызывает этот выбор при отрисовке.
Встроенный словарь `russian_names()` и `transliterate_to_russian()` удалены.

В русском режиме `name_ru` / `NAME_RU` либо `name:ru` имеет приоритет даже при
сохранённом `cities_label_field="name"`. Регистр ключей несущественен.
При отсутствии перевода используется исходное имя согласно резервным полям,
без транслитерации и исправления орфографии. В английском режиме старое
резервное `name_ru` не заставляет выводить русский текст; явно выбранное
русское поле при этом остаётся допустимым. Поддерживаются `ru`, `RU`, `ru-RU`
и `ru_RU.UTF-8`.

Настройки существующего объекта OverlayHandler — плоские, например:

```json
{
  "cities_locale": "ru",
  "cities_label_field": "",
  "cities_fallback_fields": ["name_ru", "name", "nameascii"]
}
```

Это фрагмент, а не замена всей конфигурации. `cities_type` — числовой фильтр
состава городов, не название поля. В интерфейсе значение «Язык подписей» — `ru`.
После обновления C++ требуется обычная пересборка/установка проекта вместе
с обновлёнными ресурсами. Затем применить настройки или перезапустить приложение,
чтобы сбросить кэш подписей. Для установленной станции нужно обновить именно
используемую копию ресурсов, а не только каталог исходников. Во время обычной
отрисовки интернет не нужен: названия уже находятся в поставляемом GeoJSON.

## Проверки

```sh
python3 -m unittest discover -s tests/maps -v
g++ -std=c++17 -Wall -Wextra -Werror -Isrc-core \
  tests/maps/test_city_name_resolver.cpp -o /tmp/test-city-names
/tmp/test-city-names resources/maps/ne_10m_populated_places_simple.json
```

31 проверка Python покрывает сохранность данных, однозначность, исторические
координаты, хеши исключений, пустые переводы, атомарный отказ, повторный запуск
и отсутствие старой транслитерации. Тест C++ содержит 23 отдельных проверки и
дополнительно проходит весь каталог: 6 209 дословных русских названий и 1 133
резервных исходных названия.

`.github/workflows/city-names-ru.yml` запускает проверки, синхронизирует
закреплённый источник, проверяет повторяемость и коммитит только итоговый GeoJSON
и отчёт в ту же ветку. При неуспешных проверках данные не коммитятся.
`resources/maps/city_names_ru.report.json` содержит контрольные суммы,
счётчики, полный список отсутствующих переводов и диагностические сведения.
