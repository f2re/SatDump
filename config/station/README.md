# ⚙️ Примеры конфигурации

[← Главная](../../README.md) · [Полный справочник параметров](../../docs/ru/station/CONFIGURATION.md)

| Файл | Назначение |
|---|---|
| [station.json](station.json) | Источники, очередь, пути, лимиты и подпись сайта |
| [processing.json](processing.json) | Дополнения к настройкам обработки и презентации SatDump |

Это **шаблоны**, а не активная конфигурация установленной станции. При первой установке они создают `/etc/satdump-station/*.json`. При обновлении новые образцы сохраняются как `.example`, а пользовательские параметры не подменяются.

Источник `meteor_iq` — выключенный пример; его параметры не являются универсальным способом декодировать любую запись Meteor. Сначала проверьте формат и частоту дискретизации. Для готовых продуктов передавайте `.ready` последним. [Входные данные](../../docs/ru/station/INPUTS.md).

После редактирования активных JSON нужен перезапуск воркера. Изменение рецепта может вызвать новую обработку всех доступных исходных данных. `max_items` не очищает диск.

Файл `release-request.txt` может создаваться здесь как заявка выпуска: он попадает под фильтр workflow. Само наличие файла не запускает деплой без соответствующего события и маркера. [Порядок выпуска](../../docs/ru/station/BUILD_RELEASE.md).
