# 🖥️ Службы SatDump Station

[← Главная](../../README.md) · [Архитектура](../../docs/ru/station/DATAFLOW.md) · [Сайт](../../docs/ru/station/WEBSITE.md)

| Файл | Назначение |
|---|---|
| [station.py](station.py) | Конфигурация, файловый вход, SQLite-очередь, обработка, публикация, HTTP |
| [web/index.html](web/index.html) | Структура русскоязычного интерфейса |
| [web/app.js](web/app.js) | Каталог, фильтры, предзагрузка, слайд-шоу и статус |
| [web/style.css](web/style.css) | Вёрстка галереи и режима презентации |

На установленной системе запускаются `satdump-worker` и `satdump-web` под разными пользователями. Веб-служба читает только публикационные материалы; исходники наблюдений и очередь не являются HTTP-ресурсами.

Не запускайте `station.py` из случайного системного Python на Astra вместо launcher: бинарный пакет имеет собственное окружение. Не редактируйте HTML в `current` для постоянного изменения — обновление версии заменит код. [Команды](../../docs/ru/station/REFERENCE.md) · [Тесты](../../tests/station/README.md).
