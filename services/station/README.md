# Службы SatDump Station и спутниковый экран

`station.py` сохраняет файловые входы, очередь и нативную обработку.
`board.py` подключает публикацию, `satellite.py` формирует серверный манифест,
`control.py` предоставляет ограниченный API с ревизиями и авторизацией.

`web/sat` — спутниковый экран «Орбита», `web/settings` — локальные настройки.
Исходная галерея `web/index.html` сохранена для совместимости, но главный маршрут
BOARD открывает спутниковый экран. Отдельный PHP/Node-сервер не требуется.

[Развёртывание, контракт и проверки](../../docs/ru/station/SATELLITE_WEB.md).
В полном Station-пакете используются штатный Apache2 и отдельные непривилегированные
службы worker/control/board/web. Не редактируйте файлы в установленном `current`:
обновление заменит код; настройки сохраняйте через API.
