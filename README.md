# SatDump 1.2.2 · Astra / станция спутниковых наблюдений

Рабочая ветка: **`release/1.2.2`**. Декодирование, цветосинтез, научное оформление и автономная веб-галерея.

## Что запускать

| Задача | Команда |
|---|---|
| Посмотреть доступные действия | `./station.sh help` |
| Собрать полный пакет Astra 1.6: движок, Python, воркер, сайт | `./station.sh build --jobs 2` |
| Установить готовый распакованный пакет без сети | `sudo ./install.sh` |
| Открыть установленный сайт | `http://127.0.0.1:8090/` |
| Посмотреть очередь / журналы | `sudo satdump-station status` / `sudo satdump-station logs` |
| Собрать только прежний CLI-бандл без сайта | `./build.sh` |

**Не путайте пакеты:** Astra 1.6 использует отдельную сборку `glibc224`; опубликованный ранее `astra17/glibc228` её не заменяет. GitHub Actions сборочного профиля на Ubuntu не доказывает работу на установленной Astra.

```text
station.sh / install.sh       понятные точки входа
services/station/             очередь SQLite, воркер, HTTP и статический сайт
config/station/               примеры конфигурации станции и обработки
scripts/station/              сборка, упаковка, установка, SSH-развёртывание
scripts/astra/                существующие нативные/portable сборщики движка
src-cli/, src-core/, plugins/ исходники SatDump; структура CMake сохранена
build/                       промежуточные результаты, не устанавливать
dist/station/                готовые полные офлайн-пакеты
```

Службы не используют Docker, Node.js, pip или интернет. Docker может использоваться **только в CI** для независимой проверки старой пользовательской среды. Настройки и архив находятся вне каталога кода и не заменяются обновлением.

Обычный PNG/JPEG публикуется как готовое изображение: канал, время наблюдения и физический смысл цветов не восстанавливаются из цвета пикселей. Для полноценного пересчёта требуются каналы `product.cbor` или запись с корректно заданным декодером.
