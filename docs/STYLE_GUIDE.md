# Правила документации

[Каталог документов](README.md)

Документ описывает назначение, настройки, команды и результат работы существующего кода. Планы разработки не включаются в эксплуатационную инструкцию. Вместо оценок «удобный», «полностью готовый» и «всё работает» указываются функция, ограничение или проверка.

У страницы один заголовок первого уровня. Для разделов, на которые ссылаются другие страницы, сохраняются явные якоря. Параметр подробно описывается в одном справочнике; остальные страницы ссылаются на него. Повторяющиеся предупреждения и пересказы содержания удаляются, условия безопасности и возможной потери данных сохраняются.

Перед командами указывается среда выполнения: исходники, распакованный пакет или установленная станция. Команды изменения конфигурации и удаления данных отделяются от диагностики. Демонстрационные адреса и файлы обозначаются как примеры. JSON приводится без комментариев; законченные сценарии Bash должны проходить `bash -n`.

Время наблюдения не смешивается с временем обработки. Форматы и правила UTC описаны в [справочнике времени](ru/station/UTC_AND_SCHEDULER.md). Даты испытаний и номера выпусков относятся только к проверенным ревизиям. Тест с контрольным генератором не называется проверкой радиодекодирования; проверка на совместимой ОС не называется приёмкой Astra.

Ссылки внутри проекта — относительные. Сведения о выпуске сопровождаются ссылкой на конкретный тег или запуск CI. Авторские уведомления и лицензии стороннего кода сохраняются.

## Проверка и экспорт

Из корня исходников:

```bash
python3 scripts/docs/check.py
python3 -m unittest discover -s tests/docs -v
python3 scripts/docs/export.py --output /tmp/satdump-docs --revision "$(git rev-parse HEAD)"
python3 scripts/docs/check.py --root /tmp/satdump-docs
```

Проверка охватывает страницы из `docs/navigation.json`: заголовки, ссылки, якоря, JSON и синтаксис Bash. Она не выполняет примеры и не оценивает смысл текста. Остальные описания продуктов и сторонние документы проверяются при изменении соответствующей функции.

Экспорт сохраняет главы и иллюстрации локально. Ссылки на не включённый исходный код закрепляются на указанной ревизии и требуют сети. Экспорт документации не содержит исполняемый пакет Station.
