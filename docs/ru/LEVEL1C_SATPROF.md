# Физический Level‑1C для SatProf

В ветке `release/1.2.2` доступна команда экспорта количественных продуктов SatDump:

```bash
bash scripts/astra/run.sh -- \
  level1c \
  /data/pass/MTVZA \
  /data/pass/MTVZA/satprof-level1c \
  --instrument mtvza_gy \
  --satellite METEOR-M2-4 \
  --overwrite
```

Команда принимает каталог продукта с `product.cbor` либо сам файл `product.cbor`.

## Что сохраняется

Для каждой группы каналов одинакового пространственного разрешения создаются:

- `raw_counts.u16` — исходные цифровые отсчёты без нормализации;
- `brightness_temperature.f32` — яркостная температура, только когда у продукта есть действующий калибратор SatDump;
- широта, долгота, время, положение в скане и спутниковый зенитный угол;
- флаг качества и координаты исходного пикселя;
- `satprof-level1c.json` с размерностями, единицами, каналами и CRC32;
- общий `satprof-level1c-index.json`.

Формат не зависит от NetCDF и пригоден для закрытого контура Astra Linux.

## Важное ограничение МТВЗА‑ГЯ

Текущие декодеры МТВЗА в SatDump сохраняют исходные 16-битные отсчёты, но не содержат штатной абсолютной калибровки всех каналов в яркостную температуру. Поэтому экспортёр устанавливает:

```json
{"calibration_state":"raw_counts"}
```

и заполняет массив яркостной температуры значениями `NaN`. SatProf использует такие продукты для викарного обучения преобразования `count → TB` по коллокациям с радиозондами и расчётами RTTOV. Сырые отсчёты никогда не маркируются как кельвины.

Для приборов и каналов с зарегистрированным калибратором SatDump формируются физические TB и состояние `calibrated` либо `partial`.

## Параметры

```text
--channels 1,2,3       выбрать каналы по имени
--instrument NAME      задать идентификатор прибора SatProf
--satellite NAME       задать аппарат
--stride N             экспортировать каждый N-й пиксель
--require-calibrated   завершиться ошибкой без полного набора TB
--overwrite            безопасно пересоздать каталог экспорта
```

## Проверка установки

```bash
bash scripts/astra/run.sh -- level1c --help
```

SatProf выполняет эту проверку вместе с `satdump version` в глубоком readiness-контроле.
