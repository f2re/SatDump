# CI validation marker

Этот файл запускает pull-request проверку полного состояния ветки `release/1.2.2` после ревью двух вариантов оформления, ориентации «север сверху» и Astra Linux-профилей.

После успешного слияния он остаётся как запись о том, что проверка выполнялась через PR, а не только через прямые коммиты в релизную ветку.
