## Проверка выбранного архива

Скачайте архив и файл `.sha256` из одного доверенного выпуска. [Установка](station/INSTALL.md) проверяет также внутренний `SHA256SUMS`. Совпадение суммы подтверждает целостность, а не безопасность неизвестного отправителя.

Успешные тесты документации не доказывают сборку. Сборка не доказывает приёмку на физической Astra. Публикация GitHub Release не устанавливает пакет на пользовательские станции. Для каждого нового архива нужны своя ревизия, суммы и отчёты. Прежние вложения не перезаписываются.
