| Проверки выпуска | [Run 34356459004](https://github.com/f2re/SatDump/actions/runs/34356459004) |

К архиву приложен файл `.sha256`. Внутренний `SHA256SUMS` охватывает 2101 файл. Локально на встроенном Python 3.5 выполнены все 81 тест; в отдельных CI-средах проверки, требующие отсутствующих nginx/git или прав root, отмечаются как пропущенные, а не как выполненные.

**Подтверждено для итогового архива:** запуск и установка без сети в независимом Debian Stretch; установка на чистой Ubuntu VM с настоящим systemd; автозапуск worker/WEB/control; авторизация API и запрет чтения приватных файлов веб-пользователем; применение ревизии между заданиями; публикация контрольного PNG с неизменными байтами и полным JSON-паспортом; сохранность настроек и продукции при повторной установке; запуск nginx и откат к встроенному серверу; восстановление после отказа на занятом порту; сохранность очереди и публикации после перезапуска служб. Все девять групп приёмки в отчёте завершились успешно.

**Не подтверждено этим выпуском:** физическая Astra 1.6 и её мандатные политики, контрольная радиозапись, полная перезагрузка ОС целевой станции. В проверке продукции использовался синтетический PNG, а не радиоприём. Astra 1.5/1.7 этим установщиком не поддерживаются. Развёртывание на пользовательский узел не выполнялось.

Движок и runtime взяты побитно из ранее собранного и проверенного офлайн-пакета ревизии `d7eff18016debaeb5719161d89b218fbbae4b1c7`, [run 34349962244](https://github.com/f2re/SatDump/actions/runs/34349962244). Все исходные данные их сборки проверены на неизменность. Поле `component_provenance` сохраняет их отдельную исходную ревизию, SHA-256 исходного архива и ревизию нового Station. Предыдущий установщик не используется. Проверки установки повторно выполнены именно на новом архиве.

Новый дизайн/веб-интерфейс не включён. WEB устанавливается автоматически и предоставляет продукцию и API; пользовательская статическая сборка подключается позже через `ui-deploy`. Подробности: [руководство BOARD](station/BOARD_INFRASTRUCTURE.md), в бинарном пакете — `BOARD_INFRASTRUCTURE.ru.md`.
