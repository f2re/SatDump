# 🛰️ SatDump Station — руководство оператора и администратора

[← Главная](../../../README.md) · [Вся документация](../../README.md) · [Релизы](../RELEASES.md)

Station обрабатывает файлы приёмника и публикует изображения с паспортами. Целевая система — Astra Linux 1.6 x86_64. Работают три службы systemd: обработчик, веб-сервер и управляющий API; nginx использует дополнительную внутреннюю службу BOARD.

Время, синхронизация и очередь: [UTC и планировщик](UTC_AND_SCHEDULER.md).

[МТВЗА: обработка и защита от сбоев](MTVZA_PROCESSING.md) · [Состояние выпусков](../RELEASES.md). Функции после Station 22 доступны только в заново собранном пакете из этой ветки.

## 📍 Где выполняются команды

| Обозначение | Значение |
|---|---|
| **Исходники** | Клон `f2re/SatDump`, ветка `release/1.2.2`; присутствуют CMake и исходники |
| **Пакет** | Распакованный `astra16-station-…tar.gz`; присутствуют `engine/` и `runtime/` |
| **Станция** | Astra после успешного `sudo ./install.sh`; команды доступны как `satdump-station` |
| **Машина развёртывания** | Доверенный компьютер с SSH-маршрутом до станции |

`/opt/satdump-station/current` содержит **код**. `/etc/satdump-station` — **базовая конфигурация и политика**; действующая ревизия API хранится в `/var/lib/satdump-station/control/active.json`. `/var/lib/satdump-station` — **данные**. Редактирование `config/station` в клоне не меняет установленную станцию.

## ✅ Минимальная приёмка

| Проверка | Ожидаемый результат |
|---|---|
| Контрольная сумма выбранного архива | `OK`; архив из доверенного источника |
| `systemctl is-active satdump-worker satdump-web satdump-control` | Все три службы активны |
| Контрольный PNG | Появился в галерее; исходный файл не изменился |
| Контрольный набор каналов + `.ready` | Получены новые презентационные PNG и паспорта |
| Перезапуск / перезагрузка | Архив доступен, очередь восстановлена |
| Контрольная радиозапись | Результат сопоставлен с обычным SatDump той же версии |

Контрактные тесты содержат синтетические данные. Реальная радиозапись, браузер Astra, её мандатный доступ и сетевой каталог требуют отдельной приёмки.
