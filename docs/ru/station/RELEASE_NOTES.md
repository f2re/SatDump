# Следующий выпуск Station / BOARD: МТВЗА и контроль продукции

Материал для следующего предварительного выпуска из ветки `release/1.2.2`. Этот файл не означает, что новый архив уже опубликован. Состав готовых пакетов: [таблица выпусков](https://github.com/f2re/SatDump/blob/release/1.2.2/docs/ru/RELEASES.md).

## Изменения относительно Station 22

МТВЗА собирает полные сканы, отмечает пропуски и восстанавливает обработку на следующем скане. Пустой CBOR без строк больше не создаётся. Добавлены отчёты декодирования и цветосинтеза, контроль обязательных приборов через `required_instruments`, восстановление неполных публикаций и предупреждения галереи.

Новые микроволновые RGB сохранены как экспериментальные комбинации цифровых отсчётов. Легенды не приписывают им неподтверждённые классы осадков, града, льда, влажности или биомассы. Время наблюдения не заменяется временем обработки; отсутствующая геопривязка не дополняется проекцией другого аппарата.

README, инструкции, схема API и локальная справка сайта согласованы с текущими контрактами. Сохранены UTC, встроенный сервер, API с авторизацией, полные/компактные изображения и отдельный нативный экспорт `online-board`.

## Проверки перед публикацией

Для конкретного архива обязательны сборка, проверка его состава и ABI, Python 3.5/Pillow, запуск без сети, установка на одноразовом systemd-стенде, WEB/API, права, nginx и откат. Результаты записываются в `STATION-ACCEPTANCE.json` и `RELEASE-SMOKE.json` с точной ревизией. Нативные сценарии МТВЗА используют синтетические кадры. До получения отчётов нельзя считать эти этапы пройденными новым архивом.

## Установка

Используется полный бинарный пакет для Astra Linux 1.6 x86_64. Проверяются `.tar.gz.sha256` и внутренний `SHA256SUMS`; после распаковки запускается `sudo ./install.sh`. Docker, Node.js и pip на целевой станции не нужны. По умолчанию галерея доступна на `http://127.0.0.1:8090/`.

Проверка часов: `satdump-station time-status`. Источники и обязательные приборы задаются в центральной конфигурации. [Настройки](https://github.com/f2re/SatDump/blob/release/1.2.2/docs/ru/station/CONFIGURATION.md) · [МТВЗА и отчёты](https://github.com/f2re/SatDump/blob/release/1.2.2/docs/ru/station/MTVZA_PROCESSING.md).

Испытания на физической Astra, мандатный доступ, точность NTP, радиометрическая калибровка, реальная радиозапись и геопривязка требуют отдельной приёмки. Пользовательские станции автоматически не обновляются.
