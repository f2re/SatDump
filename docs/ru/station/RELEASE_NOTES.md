# SatDump Station / BOARD — UTC и автономная галерея

Пакет для Astra Linux 1.6 x86_64: SatDump с базисом glibc 2.24, отдельная среда Python/Pillow, установщик, файловая очередь, встроенная веб-галерея и авторизованный API настроек. Все компоненты Station и документация берутся из указанной в выпуске ревизии ветки `release/1.2.2`.

## Изменения

Единый вывод UTC в службах и галерее, нормализация начала и конца наблюдения, поддержка перехода через полночь. Повторные попытки и проверка работоспособности используют монотонные часы. Рабочие копии сохраняют mtime; отсутствующее время наблюдения не заменяется временем файла. Лента сортируется по наблюдению, а не по пересчёту.

Галерея открывается по корневому адресу без отдельной установки сайта. Пути входов, форматы, конвейеры и рецепты задаются в центральной конфигурации; активная ревизия API применяется между заданиями. Публикуются полные и компактные PNG с паспортами. Сохранён экспорт `online-board` нативного движка. Обновлены инструкции по настройкам, UTC, готовности файлов, резервированию и откату.

## Проверки пакета

Публикация разрешена после тестов станции на Python 3.5/Pillow, проверки распакованного архива в Debian Stretch без сети и без системного Python, установки на чистой Ubuntu VM с настоящим systemd, проверки WEB/API, прав, nginx, повторной установки и отката. Дополнительная приёмка проверяет встроенную галерею, UTC, интервал через полночь, сортировку, сохранение паспортов и отсутствие дублей после перезапуска служб.

К выпуску прилагаются SHA-256, `STATION-ACCEPTANCE.json` и `RELEASE-SMOKE.json`. Отчёты относятся к точному архиву и ревизии этого выпуска. Контрольные изображения в установочных тестах не являются спутниковыми наблюдениями.

## Установка

Проверьте файл `.tar.gz.sha256`, распакуйте архив и выполните `sudo ./install.sh`. По умолчанию используется встроенный сервер; nginx необязателен. На целевой машине не требуются Docker, Node.js, pip и сборочные инструменты. Обычный адрес галереи — `http://127.0.0.1:8090/`. Проверка времени — `satdump-station time-status`.

Это предварительный инженерный выпуск. Испытания физической Astra, её мандатных политик, точности NTP, реального радиодекодирования и полной перезагрузки целевого компьютера не заменяются проверками CI. Пользовательские станции автоматически не обновляются.
