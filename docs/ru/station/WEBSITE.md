## 1. Назначение сайта

Сайт показывает уже опубликованные материалы. Он не предоставляет административные операции, загрузку входов, редактирование настроек или запуск декодера из браузера. Выдаётся статический интерфейс и ограниченный набор файлов из `public`.

| Элемент | Поведение |
|---|---|
| Большое изображение | Обзорная копия без обрезки; исходный файл открывается отдельно |
| Фильтр источника | Точное совпадение `source` |
| Фильтр спутника | Точное совпадение подписи спутника |
| Поиск | Подстрока в названии продукта и прибора |
| Дата / подпись UTC | **Текстовая подстрока**, не календарный диапазон |
| Лента | Первые 60 карточек; «Показать ещё» добавляет следующие 60 |
| Оригинал | Полноразмерный публикационный PNG/JPEG, не IQ/каналы |
| Паспорт | JSON метаданных конкретной карточки |

Каталог сортируется по **времени публикации**, не по времени спутникового наблюдения. При переработке старой записи её новая версия может оказаться в начале ленты. Скрытые пределом `max_items` карточки не удаляются с диска.

## 2. Управление показом

| Действие | Управление |
|---|---|
| Начать автоматический показ | Кнопка «Презентация» |
| Приостановить | «Пауза» или пробел вне поля ввода |
| Предыдущий / следующий кадр | Кнопки стрелок или клавиши ← / → |
| Полноэкранный режим | «На весь экран»; при ограничении браузера — F11 |
| Вернуться к ленте | «К архиву» |

Номинальный интервал автоматической смены — 10 секунд после загрузки кадра. Следующее превью предзагружается. Пока новая картинка загружается или её загрузка не удалась, предыдущий видимый кадр сохраняется. В скрытой вкладке автоматическое перелистывание приостанавливается.

> [!NOTE]
> Это слайд-шоу продуктов, **не временная анимация одного и того же канала на единой сетке**. Разные спутники, приборы и времена могут чередоваться. Для тематического показа сначала задайте фильтры.

## 3. Время и статус

`acquisition_time` показывается как подпись из паспорта. При его отсутствии явно написано, что время наблюдения неизвестно; отдельно отображается время изменения входного файла. `published_at` относится к работе станции. Они не взаимозаменяемы.

Браузер опрашивает каталог и состояние примерно каждые 15 секунд. При ошибке связи не удаляет уже загруженный кадр. Это не полноценный офлайн-кеш браузера: после обновления страницы при недоступном сервере интерфейс может не загрузиться. Для автономной работы сервер станции должен быть доступен по локальной сети или localhost.

## 4. Разрешённые HTTP-ресурсы

| Путь | Содержимое / режим |
|---|---|
| `/`, `/index.html` | Главная страница |
| `/app.js`, `/style.css` | Локальные ресурсы интерфейса |
| `/catalog.json` | Каталог `satdump.gallery/1` |
| `/worker.json` | Последний сигнал воркера |
| `/health.json` | Состояние веб-службы и оценка свежести воркера |
| `/items/<64-hex-id>/<NNN>.png` или `.jpg` | Оригинал публикационной карточки |
| `/items/<64-hex-id>/<NNN>-preview.jpg` | Превью |
| `/items/<64-hex-id>/<NNN>-thumb.jpg` | Миниатюра |
| `/items/<64-hex-id>/<NNN>.json` | Паспорт |

`NNN` — трёхзначный номер, например `000`. Внутренний `item.json`, журналы, SQLite и конфигурация не входят в разрешённую HTTP-выдачу. Просмотр каталогов отсутствует. Поддерживаются GET и HEAD; POST отклоняется с 405.

Статические индексные данные выдаются с `no-store`, опубликованные элементы — как неизменяемые. JSON индекса заменяется атомарно; URL готового набора не переиспользуется для другой версии.

## 5. Как читать health.json

Описательный пример формата, не состояние реальной станции:

```json
{
  "updated_at": 1788868800,
  "phase": "idle",
  "queue": {"done": 12, "pending": 1},
  "sources": {},
  "stale_after": 60,
  "web_alive": true,
  "worker_alive": true
}
```

| Поле | Смысл |
|---|---|
| `web_alive` | HTTP-процесс отвечает |
| `worker_alive` | Время с последнего heartbeat меньше `stale_after` |
| `phase` | Фаза, например `scanning`, `hashing`, `copying`, `verifying`, `processing`, `idle` |
| `queue` | Число заданий по состояниям; отсутствующий ключ обычно означает ноль |
| `sources` | Обнаруженные проблемы, например `unavailable` или `low_disk` |

Endpoint может вернуть **HTTP 200 при `worker_alive=false`**. Мониторинг должен проверять JSON, а не только код HTTP. Обычный `idle` не гарантирует, что все источники доступны. Большой обход файлов, подготовка изображений или каталогизация могут задержать heartbeat; это повод для диагностики, не автоматическое доказательство зависания.

## 6. Безопасность и ограничения

Сервер ограничивает число параллельных обработчиков и время ожидания соединения, проверяет допустимые пути, не исполняет данные из паспорта. В HTML метаданные подставляются как текст. Эти меры не заменяют защищённый внешний прокси, TLS и контроль доступа.

Не выставляйте встроенный сервер со старым Python/Pillow напрямую в интернет. На старых браузерах отдельно проверьте JavaScript, CSS и полноэкранный API. В текущем CI проверка синтаксиса JavaScript не равна полноценному тесту интерфейса в браузере Astra.
