## Галерея

Встроенная галерея открывается по корневому адресу станции. HTML, JavaScript и стили находятся в `services/station/web` и входят в пакет. Внешние шрифты, библиотеки и CDN не требуются. Интернет не нужен; сервер станции должен быть доступен по localhost или локальной сети.

Галерея показывает изображения, паспорта, фильтры источника и спутника, поиск по продукту и прибору. Поле даты ищет подстроку в UTC-подписи и ISO-датах начала/конца, а не задаёт календарный диапазон. Первоначально выводятся 60 карточек; кнопка «Показать ещё» добавляет следующую порцию.

Каталог читается из `/api/v1/board` с учётом настроенных фильтров видимости. При работе базовой галереи без BOARD используется `/catalog.json`. Фильтр скрывает карточку из каталога, но не удаляет файл и не закрывает ранее опубликованный URL.

Карточки с известным временем наблюдения упорядочены по его началу, от новых к старым. Остальные идут после них по времени публикации. `max_items` ограничивает выдачу, но не очищает хранилище.

## Просмотр и автоматический показ

«Презентация» включает смену кадров через 10 секунд после загрузки изображения. Следующий кадр предзагружается. Стрелки и клавиши ←/→ перелистывают кадры; пробел вне поля ввода приостанавливает показ. В скрытой вкладке смена кадров приостанавливается. Для выхода служит «К архиву», для полного экрана — кнопка или F11.

При ошибке загрузки сохраняется предыдущий кадр. Каталог и состояние запрашиваются каждые 15 секунд. После перезагрузки страницы при недоступном сервере локальная копия сайта не гарантируется: отдельного автономного кеша браузера нет.

«Оригинал» открывает полноразмерный публикационный PNG/JPEG. Сырые записи, каналы, очередь и журналы не выдаются через сайт. JSON-паспорт доступен отдельно и сохраняет исходные метаданные.

## Время

Подпись наблюдения нормализована в UTC; локальный часовой пояс браузера на неё не влияет. Поля `acquisition_start_utc` и `acquisition_end_utc` пригодны для программной обработки. Если время отсутствует либо некорректно, оно не вычисляется из mtime: время изменения файла выводится отдельно. [Полный контракт времени](UTC_AND_SCHEDULER.md).

## Маршруты

| Путь | Назначение |
|---|---|
| `/`, `/index.html` | Встроенная галерея или подключённый дополнительный интерфейс |
| `/app.js`, `/style.css` | Локальные файлы встроенной галереи |
| `/api/v1/board` | Каталог `satdump.board/1` |
| `/api/v1/board/status` | Применённая ревизия настроек и фаза работы |
| `/catalog.json` | Совместимый каталог `satdump.gallery/1` |
| `/worker.json` | Последнее состояние обработчика |
| `/health.json` | `web_alive`, `worker_alive`, состояния очереди и источников |
| `/health/ready` | HTTP 200 при свежем сигнале обработчика; 503 иначе |
| `/items/<id>/<NNN>.png` или `.jpg` | Публикационный оригинал |
| `/items/<id>/<NNN>-preview.jpg` | Обзорная копия |
| `/items/<id>/<NNN>-thumb.jpg` | Миниатюра |
| `/items/<id>/<NNN>.json` | Паспорт |

`id` содержит 64 шестнадцатеричных символа, `NNN` — трёхзначный номер. Публичная служба поддерживает GET и HEAD, не принимает загрузки и не запускает обработку по HTTP. Управляющий API находится на отдельном loopback-порту и требует авторизацию.

Индексы выдаются с `no-store`. Завершённые элементы имеют неизменяемые URL. Публикация каталога выполняется атомарно.

## Состояние обработчика

`worker_alive` означает свежий сигнал процесса в пределах той же загрузки ОС. Возраст сигнала определяется монотонными часами. Это не оценка точности UTC и не подтверждение доступности всех источников.

`/health.json` может вернуть HTTP 200 с `worker_alive=false`; проверяется содержимое JSON. Для проверки готовности по коду HTTP используется `/health/ready`. Поле `sources` сообщает обнаруженные ошибки входов и нехватку места, `queue` — число заданий по состояниям. Длительный обход или подготовка изображений могут задержать сигнал состояния.

## Дополнительный интерфейс

Собственный каталог с `index.html` подключается командой `sudo satdump-station ui-deploy /путь/к/каталогу`. Он имеет приоритет над встроенной галереей. Файлы размещаются отдельно от кода движка; обновление Station не заменяет их.

Сценарии и ресурсы дополнительного сайта также должны быть локальными. Политика CSP запрещает внешние CDN и встроенные в HTML сценарии. Встроенный сервер предназначен для доверенной сети; публичный доступ требует отдельной защиты.

Реализация: [BOARD](../../../services/station/board.py), [HTTP](../../../services/station/station.py), [JavaScript](../../../services/station/web/app.js).
