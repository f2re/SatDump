# Картографические слои, города и пункт приёма

Документ относится к ветке `release/1.2.2` форка `f2re/SatDump`.

Presentation mode может наносить государственные границы, береговую линию,
координатную сетку, населённые пункты и отдельно выделенный пункт приёма. Слои
строятся только при наличии достоверной проекционной или навигационной
конфигурации.

## Что изменено

- названия городов по умолчанию формируются на русском языке;
- белый полупрозрачный текст получил графитовую обводку;
- старые чисто-красные подписи заменяются новым стилем, если пользователь не
  задавал свой цвет;
- подписи сортируются по значимости и не пересекаются;
- на мировой карте остаются главным образом столицы, на региональной карте
  детализация увеличивается;
- пункт приёма рисуется поверх городов янтарным маркером и отдельной подписью;
- координаты, размеры, цвета и прозрачность задаются в конфигурации.

## Пункт приёма

Базовые координаты и название станции задаются в `satdump_cfg.json`:

```json
{
  "satdump_general": {
    "qth_lat": {"value": 59.9386},
    "qth_lon": {"value": 30.3141},
    "default_qth_label": {"value": "Санкт-Петербург"}
  }
}
```

Если координаты равны `0, 0`, а название — `QTH`, точка считается
ненастроенной и не рисуется. Для отдельного композита значения можно
переопределить:

```json
{
  "draw_qth_overlay": true,
  "qth_lat": 59.9386,
  "qth_lon": 30.3141,
  "qth_label": "Санкт-Петербург"
}
```

## Полная настройка

Параметры располагаются рядом с существующими настройками картографических
слоёв в конфигурации композита или проекции:

```json
{
  "draw_map_overlay": true,
  "draw_shores_overlay": true,
  "draw_cities_overlay": true,
  "draw_qth_overlay": true,
  "draw_latlon_overlay": false,

  "cities_locale": "ru",
  "cities_label_field": "name_ru",
  "cities_fallback_fields": ["name_ru", "name", "nameascii"],
  "cities_mode": "auto",
  "cities_type": 1,
  "cities_scale_rank": 4,
  "cities_size": 26,
  "cities_max_labels": 120,
  "cities_avoid_overlap": true,
  "cities_prioritize_capitals": true,
  "cities_collision_padding": 4,
  "cities_outline_width": 2,
  "cities_color": [0.97, 0.98, 1.0, 0.94],
  "cities_outline_color": [0.12, 0.14, 0.17, 0.82],

  "qth_lat": 59.9386,
  "qth_lon": 30.3141,
  "qth_label": "Санкт-Петербург",
  "qth_label_prefix": "Пункт приёма: ",
  "qth_color": [0.94, 0.72, 0.24, 1.0],
  "qth_text_color": [1.0, 0.98, 0.90, 0.98],
  "qth_outline_color": [0.12, 0.13, 0.15, 0.90],
  "qth_marker_size": 8,
  "qth_outline_width": 2,
  "qth_font_scale": 1.25,
  "qth_halo_alpha": 0.28,

  "latlon_color": [0.55, 0.63, 0.72, 0.24]
}
```

Цвет задаётся как `[R, G, B, A]` в диапазоне `0…1`. Трёхкомпонентные старые
значения `[R, G, B]` также поддерживаются.

## Русские названия

Для `cities_locale: "ru"` используется цепочка:

1. `cities_label_field`, если поле задано;
2. `name_ru` или `name:ru`;
3. `cities_fallback_fields`;
4. `name`, `nameascii`, `namepar`;
5. встроенный словарь общеупотребительных русских названий;
6. транслитерация оставшегося латинского названия.

Поэтому старый набор Natural Earth не оставляет подписи латиницей. Для редкого
города точное написание можно добавить в поле `name_ru` используемого GeoJSON
или в словарь `common/map/city_labels.cpp`. Псевдоним `cities_language`
равнозначен `cities_locale`.

## Генерализация

| `cities_mode` | Поведение |
|---|---|
| `auto` | режим определяется по видимому диапазону широт и долгот |
| `world` | столицы государств |
| `continent` | столицы и крупнейшие мировые города |
| `regional` | столицы, региональные центры и значимые города |
| `local` | все города, разрешённые `cities_type` и `cities_scale_rank` |

`cities_type` сохраняет штатную семантику SatDump: `0` — столицы государств,
`1` — столицы государств и регионов, `2` — города до указанного ранга. Для
presentation mode рекомендуется сочетание `cities_type: 1` и
`cities_mode: "auto"`.

При `cities_avoid_overlap: true` renderer сначала сортирует кандидатов по
статусу столицы, населению и рангу, затем измеряет фактическую ширину текста,
пробует несколько положений вокруг маркера и пропускает подпись, если свободного
места нет. `cities_collision_padding` задаёт дополнительный промежуток в
пикселях, а `cities_max_labels` — жёсткий верхний предел.

## Цвета и композиция

Рекомендуемый стиль городов:

```json
{
  "cities_color": [0.97, 0.98, 1.0, 0.94],
  "cities_outline_color": [0.12, 0.14, 0.17, 0.82],
  "cities_outline_width": 2
}
```

Белый текст с графитовой обводкой читается на светлых облаках, тёмной воде и
красно-пурпурных ложных цветах. Прозрачность сохраняет фактуру снимка.

Рекомендуемый стиль пункта приёма:

```json
{
  "qth_color": [0.94, 0.72, 0.24, 1.0],
  "qth_text_color": [1.0, 0.98, 0.90, 0.98],
  "qth_outline_color": [0.12, 0.13, 0.15, 0.90],
  "qth_halo_alpha": 0.28
}
```

Мягкий янтарный цвет отличает станцию от городов без конфликта с
метеорологическими палитрами. Область подписи пункта резервируется до размещения
городов, а сам пункт рисуется последним.

Координатную сетку для публикационных снимков обычно лучше отключать. Если она
нужна для анализа, рекомендуется прозрачность `0.15…0.30`.

## Диагностика

В журнал выводится выбранный уровень и статистика:

```text
City labels: mode=continent, drawn=47, projected=312, overlaps=96
```

Если геопривязки нет, SatDump не пытается угадывать положение городов по
изображению. Сначала необходимо передать `proj_cfg`, GCP или модель сканирования
конкретного декодера.
