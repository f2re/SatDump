# Дополнительное ревью плашек и легенд — 21.07.2026

## Проверенный контур

Ревью выполнено для ветки `release/1.2.2` после внедрения двух макетов оформления и автоматической ориентации север-сверху.

## Что проверяется автоматически

- классификация вертикального и горизонтального кадра;
- минималистичный и презентационный макеты;
- непрерывная, категориальная и RGB-легенды;
- вертикальное и горизонтальное отражение, поворот на 180°;
- восходящий и нисходящий пролёт;
- перевёрнутая целевая проекция;
- сохранение обоих PNG и JSON-паспортов;
- совместимый файл `_annotated.png` при включённом alias;
- неизменность исходного научного растра;
- раздельное включение и отключение вариантов через JSON;
- сборка headless-профиля по логическим профилям Astra Linux 1.6 и 1.7;
- нативная контейнерная сборка в официальном Astra Linux UBI 1.7.

## Принятые решения

1. Поворот на 90° ради более удобной плашки не выполняется. Вертикальный и горизонтальный кадры получают разную компоновку, но географические оси не меняются.
2. Для north-up сначала анализируется геометрия фактического выходного изображения, затем GCP/TLE/timestamps, затем направление пролёта.
3. При восходящем хронологическом пролёте оформленная копия отражается по вертикали; исходный продукт остаётся без изменений.
4. На каждый итоговый кадр могут одновременно создаваться `minimal` и `editorial`.
5. JSON `satdump.presentation/2` фиксирует источник решения об ориентации и применённое преобразование.

## Оставшиеся эксплуатационные проверки

- реальный проход Meteor-M с пересечением высоких широт;
- реальный восходящий и нисходящий NOAA/MetOp;
- шрифты и масштабирование на Fly при нестандартном DPI;
- нативная Astra Linux 1.6 на точном оперативном обновлении организации.

Публичного официального контейнера Astra Linux 1.6 в CI не используется. Для окончательной приёмки 1.6 необходима ВМ или self-hosted runner на целевом обновлении ОС.
