# Исправление ориентации и картографических подписей

Дата проверки: 5 сентября 2026 года.

## Исходные проявления

Проверены четыре презентационных PNG из `tmp` для Metop-C/AVHRR-3 и
Метеор-М №2-3/№2-4 с МСУ-МР. На восходящих пролётах встречались зеркальная
география и перевёрнутые вместе с растром подписи. В одном продукте границы
рисовались без городов, имя Кишинёва содержало mojibake, а интервал наблюдения
мог завершаться в 2116 году.

## Причины и исправления

1. Анализ ориентации сравнивал только широты верхнего и нижнего края.
   Теперь дополнительно сравниваются долготы слева и справа. Совместная ошибка
   осей корректируется поворотом на 180 градусов, одиночная — отражением по
   соответствующей оси. Измеренные координаты сохраняются в JSON sidecar.
2. Города и пункт приёма наносились до коррекции ориентации и отражались вместе
   с изображением. Презентация теперь строится из чистого растра: сначала
   выполняется ориентация, затем координаты наложений преобразуются тем же
   способом и только после этого рисуются текст и маркеры.
3. Кэш геокорректированного наложения учитывал размер, но не изменение
   геопривязки и таблицы коррекции. Кэш и функция преобразования теперь
   обновляются при изменении любой из этих составляющих.
4. При отсутствии русского названия код принимал повреждённое UTF-8 поле раньше
   читаемого `nameascii`. Известные признаки mojibake теперь отбрасываются;
   добавлены русские варианты названий Кишинёва, Бельц, Дубоссар и Тирасполя.
5. Без опорного времени один ошибочный счётчик мог растянуть интервал на десятки
   лет. Теперь выбирается наиболее плотная группа временных меток в пределах
   шестичасового окна одного пролёта.
