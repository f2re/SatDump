# Два режима оформления снимков и ориентация кадра

Этот документ относится к ветке `release/1.2.2` форка `f2re/SatDump`.

## Что сохраняется

Оформление является дополнительным слоем. Исходный научный растр, PNG/TIFF и его геопривязка не заменяются и не изменяются.

Для итогового кадра SatDump по умолчанию сохраняет два варианта:

```text
<имя>_annotated_minimal.png
<имя>_annotated_minimal.json
<имя>_annotated_presentation.png
<имя>_annotated_presentation.json
```

При включённой совместимости также создаётся:

```text
<имя>_annotated.png
<имя>_annotated.json
```

## Минималистичный режим

`minimal` добавляет узкие информационные поля непосредственно над и под снимком:

- спутник и прибор;
- название продукта;
- интервал наблюдения и направление пролёта;
- канал, спектральный диапазон, частоту приёма и проекцию;
- компактную непрерывную, категориальную или RGB-легенду;
- краткое предупреждение об условности цветов.

Режим предназначен для оперативных сводок, автоматических каталогов и публикации большого количества кадров. Исходный спутниковый растр не масштабируется.

## Презентационный режим

`editorial`, сохраняемый с суффиксом `_annotated_presentation`, использует более выраженную визуальную иерархию:

- крупную идентификацию аппарата и прибора;
- отдельный заголовок тематического продукта;
- карточку качества, если показатели доступны;
- расширенный паспорт пролёта;
- полноценную легенду с пояснениями;
- формулы и состав R/G/B для многоканальных композитов;
- адаптивные размеры шрифтов и отступов.

Стиль остаётся строгим: без декоративных градиентов поверх научного растра, без тяжёлых теней и без изменения цветов самого снимка.

## Вертикальные и горизонтальные снимки

Компоновка определяется по отношению ширины к высоте:

- меньше `0.82` — вертикальный кадр;
- больше `1.22` — горизонтальный кадр;
- промежуточный диапазон — близкий к квадратному.

Для вертикального кадра:

- уменьшается масштаб заголовков;
- блоки переносятся на дополнительные строки;
- длинное пояснение шкалы сокращается в минималистичном варианте;
- категориальная легенда строится в одну колонку.

Для горизонтального кадра:

- допускается двухколоночная категориальная легенда;
- используются более широкие строки метаданных;
- презентационный режим сохраняет крупную, но компактную иерархию.

Поворот на 90 градусов только ради размещения плашки не выполняется: это изменило бы смысл ориентации земной поверхности. Альбомный и портретный режимы меняют компоновку, а не географию.

## Север сверху

Автоматический режим принимает решение в следующем порядке:

1. Проверяет географическую проекцию, прикреплённую к фактическому выходному растру.
2. Для исходной полосы анализирует GCP, TLE и временные метки строк.
3. При отсутствии достаточной геометрии использует направление пролёта.
4. Если определить ориентацию нельзя, сохраняет исходный кадр и отмечает это в JSON.

Для хронологически записанной полосы:

- восходящий пролёт обычно требует вертикального отражения;
- нисходящий пролёт обычно уже имеет север в верхней части.

Решение применяется только к презентационной копии. Исходный научный продукт остаётся нетронутым.

JSON-паспорт содержит:

```json
{
  "schema": "satdump.presentation/2",
  "orientation": {
    "north_up_requested": true,
    "north_up_verified": true,
    "transform": "flip_vertical",
    "pass_direction": "ascending",
    "inferred_from_projection": false,
    "inferred_from_gcps": true,
    "inferred_from_pass_direction": false
  }
}
```

## Настройка обоих вариантов

Настройки можно задать глобально через пользовательский JSON либо внутри конкретного пресета композита.

```json
{
  "presentation": {
    "enabled": true,
    "outputs": {
      "minimal": true,
      "presentation": true,
      "legacy_alias": false
    },
    "orientation": {
      "mode": "auto",
      "north_up": true
    }
  }
}
```

Эквивалентная краткая запись:

```json
{
  "presentation": {
    "outputs": ["minimal", "editorial"]
  }
}
```

### Ручной режим ориентации

Допустимые значения `orientation.mode`:

| Значение | Действие |
|---|---|
| `auto` | Проекция → GCP → направление пролёта |
| `keep` | Сохранить исходную ориентацию |
| `flip_vertical` | Отразить по вертикали |
| `flip_horizontal` | Отразить по горизонтали |
| `rotate_180` | Повернуть на 180° без интерполяции |

Ручной режим нужен только для нестандартных декодеров или архивов с известной ошибкой ориентации.

## Раздельные темы

Общая тема по-прежнему задаётся в `presentation.theme`. Дополнительно каждый вариант может иметь собственную тему.

```json
{
  "presentation": {
    "minimal": {
      "enabled": true,
      "branding": "Оперативный метеоцентр",
      "show_branding": true,
      "theme": {
        "panel": "#101820",
        "text": "#F4F7FA",
        "muted_text": "#A8B4C2",
        "accent": "#55C7E8"
      }
    },
    "editorial": {
      "enabled": true,
      "branding": "Спутниковая метеорология",
      "theme": {
        "panel": "#0E1624",
        "panel_secondary": "#172235",
        "border": "#2A3A50",
        "accent": "#4EC7E8",
        "reference_width": 1600,
        "minimum_scale": 0.58,
        "maximum_scale": 2.0
      }
    }
  }
}
```

Цвет можно задавать строкой `#RRGGBB`, `#RRGGBBAA` или массивом из трёх компонентов в диапазоне `0…1` либо `0…255`.

## Легенды

### Количественный продукт

Для температуры, отражательной способности и других непрерывных величин используется цветовая шкала с физическими единицами и делениями. Цвета шкалы должны совпадать с LUT, применённой к растру.

### Категориальный продукт

Для типа облачности, фазы, снега, воды и других классов используются цветные маркеры и подписи категорий.

### RGB-композит

Для условного многоканального композита выводятся компоненты `R`, `G`, `B`, входные каналы, длины волн, физические величины и формулы. Даже когда выражение нельзя разобрать полностью, входные каналы перечисляются.

## Проверка результата

После сборки тестовые кадры находятся в:

```text
build/astra-<версия>-<профиль>/presentation-test-output/
```

Проверяются:

- горизонтальные и вертикальные кадры;
- оба оформления;
- непрерывная, категориальная и RGB-легенды;
- вертикальное и горизонтальное отражение;
- поворот на 180°;
- восходящий и нисходящий пролёт;
- перевёрнутая пользовательская проекция.
