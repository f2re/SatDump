## 🚀 Установка и обновление

Указать проверку суммы, распаковку **конкретного архива** и запуск `sudo ./install.sh` из его корня. Напомнить о резервной копии. Перечислить изменения конфигурации; отметить, что source ZIP — не бинарный пакет.
